# Skill Package Language

Skill 形态的项目语言记录。这里保存 `SKILL.md`、`scripts/`、`templates/` 和各平台入口共用的工作流概念，帮助协作者区分建库、入库、查询、综合、检查和删除等动作。

## Language

**工作流路由**:
根据用户意图把请求分配到 init、ingest、query 等具体工作流的判断过程。路由只决定下一步走哪条流程，不直接修改知识库。
_Avoid_: 工作流执行, 命令菜单

**通用前置检查**:
除 init 外多数工作流开始前确认知识库位置、读取配置和判断输出语言的步骤。它保证后续动作落在正确知识库上。
_Avoid_: 初始化, 状态检查

**init**:
创建一个新的 llm-wiki 知识库，并生成目录结构、配置、索引、日志、研究方向和缓存文件。
_Avoid_: ingest, 添加素材, 新建页面

**ingest**:
把单个原始素材保存进知识库，并整理出素材摘要页、实体页、主题页和相关索引记录的工作流。
_Avoid_: query, digest, 文件导入

**batch-ingest**:
对一个文件夹或一批文件逐个执行 ingest 的工作流。它负责批量调度和进度汇总，不改变单个素材的处理规则。
_Avoid_: ingest, 新建知识库

**Markdown 素材包**:
一次保真捕获形成的不可变资料版本，包含原始 Markdown、本地依赖、独立阅读副本及文件哈希清单。原文按字节保存，阅读副本解析本地引用；捕获完成不等于正式摘要已采用。
_Avoid_: 摘要页面, 归档 ZIP, 原文改写

**资料身份与修订**:
资料身份在同一来源集合中持续使用，对应固定素材摘要路径；修订标识某次捕获的正文和依赖。来源集合仅保存目录指纹及相对路径，迁移后显式重新指定目录。
_Avoid_: 文件名身份, 自动目录监听, 本机路径登记

**手动增量更新**:
只读扫描来源目录，识别新增、修改、唯一改名、删除、未变化和待修复项；选中变化后捕获并通过 Review 采用摘要。删除只提示，人工补充区逐字保留，区外未知编辑阻止覆盖。
_Avoid_: 自动监听, 全量重写, 级联删除

**query**:
基于已有 wiki 页面快速回答用户问题的工作流；用户可选择仅依据 raw 原文。query 默认即时回答，值得保存时经候选采用生成衍生 query 页面。
_Avoid_: digest, ingest, 全网搜索

**digest**:
跨多个已有 wiki 页面生成综合报告候选的工作流。核对并采用后写入综合分析、对比或时间线页面及根索引日志。
_Avoid_: query, ingest, 临时总结

**lint**:
检查知识库健康状况的工作流，包含机械检查和 AI 判断类检查。lint 负责发现孤立页面、断链、矛盾、缺失引用和置信度问题。
_Avoid_: status, graph, 自动重写

**status**:
汇总知识库当前规模、素材分布、页面数量、最近活动和外挂状态的工作流。status 只报告现状，不做修复。
_Avoid_: lint, query, graph

**检索证据包**:
只读检索返回的原文片段、相对路径、章节、行号与内容哈希。wiki 和 raw 在扫描前分开；核验确认当前文件与引用相符，不代表主张本身已被证实。
_Avoid_: 向量库, 模型回答, 原文真实性认证

**Review 问题**:
有类型、原因、资料版本和生命周期的知识问题。资料变化后的问题有新的身份，旧解决状态不能永久屏蔽新版本。
_Avoid_: 自动修复, 已确认事实, 客户端任务

**研究候选**:
固定证据、生成正文和目标旧版本的待采用内容。候选可核对和重新查看，生成完成时正式 wiki、索引与日志尚未改变。
_Avoid_: 已发布页面, 原始素材, 自动入库

**候选生命周期**:
待采用候选可被显式取消或由同目标的新候选替代；已采用、取消和被替代记录保留历史身份。取消不更新正式页面，也不解决关联问题。
_Avoid_: 删除素材, 取消采用历史, 自动关闭问题

**Review 历史整理**:
把已完成记录和原始采用日志保存到可校验历史，释放活动容量的维护过程。先保存历史索引，再收缩活动状态；一致的中断副本可重试，未知冲突不覆盖。
_Avoid_: 删除历史, 提高容量常数, 知识库 ZIP 归档

**知识新鲜度**:
判断页面所记录的依据是否仍对应库内当前采用版本的结果。它与引用的字节核验独立，不判断主张在现实世界中是否正确；损坏或缺失依据不能判为当前。
_Avoid_: 原文真实性认证, 按文件修改时间判过期, 自动重写

**更新影响**:
资料变化与现有页面依赖之间的关联。可验证的旧版引用需要复核，手写来源或受限间接关联只表示潜在影响；用户显式跟踪后才创建 Review 问题。
_Avoid_: 已确认错误, 全库自动刷新, 自动解决问题

**采用**:
用户要求保存或采用后，将候选按固定发布清单写入正式页面、根索引、日志及 Review 状态。中断恢复识别已写入内容，不重新调用模型或重复记录日志。
_Avoid_: 生成候选, 自动覆盖, 重新 ingest

**知识库归档**:
带 manifest、规范相对路径和文件哈希的 Skill 知识库快照。保存原文、附件、wiki、根配置及 Review 历史；排除机器凭证、客户端数据、进程锁和临时文件。
_Avoid_: 整个仓库打包, 客户端导出, 自动监听

**归档恢复**:
校验完整归档后恢复到新目录或空目录的过程。原文与审阅历史保真，缓存失效重建；不覆盖未知文件或更改全局库指针。
_Avoid_: 合并现有库, 自动重新 ingest, 覆盖恢复

**graph**:
从 wiki 页面链接和关系信号生成知识图谱文件的工作流。graph 负责生成 Mermaid 图、交互式图谱数据和离线 HTML，不负责解释所有内容。
_Avoid_: digest, 图谱阅读, query

**delete**:
删除某份原始素材及其素材摘要页，并清理相关引用、索引、日志和缓存的工作流。delete 是级联清理，不只是删除一个文件。
_Avoid_: 隐藏素材, 取消引用, lint 修复

**手动结晶 / crystallize**:
把用户主动提供的一段有价值内容整理成 `wiki/synthesis/sessions/` 下页面的工作流。它可以记录对话或思考成果，但不会自动读取工作台当前会话；需要当前会话状态时，属于工作台的对话结晶。
_Avoid_: ingest, query 保存, 对话结晶, 自动读取当前会话

**来源总表**:
定义素材来源、匹配规则、raw 目录、提取器和回退提示的表。所有素材路由都应从来源总表读取，不应临时手写域名判断。
_Avoid_: 域名白名单, 提取器配置

**可选提取器**:
用于自动提取网页、X/Twitter、微信公众号、YouTube 或知乎内容的附加能力。可选提取器失败时，核心知识库流程仍应能通过手动入口继续。
_Avoid_: 核心依赖, 必装工具

**手动入口**:
自动提取不可用、不支持或结果为空时，让用户直接粘贴文本或提供本地文件继续处理的入口。
_Avoid_: 失败状态, 放弃处理

**外挂状态**:
可选提取器在当前环境下的可用性分类，例如未安装、环境不可用、运行失败、不支持或空结果。外挂状态用于生成可执行的回退提示。
_Avoid_: 错误码, 异常栈

**缓存命中**:
原始素材内容没有变化，且已有对应素材摘要页可复用的状态。缓存命中时不应再次调用模型重新整理同一份素材。
_Avoid_: 跳过处理, 删除缓存

**完整处理**:
长素材进入 ingest 后的标准整理路径，会生成素材摘要页，并创建或更新实体页、主题页、索引和日志。
_Avoid_: 简化处理, digest

**简化处理**:
短素材进入 ingest 后的轻量整理路径，只生成摘要页、提取少量关键概念并更新基础索引和日志。
_Avoid_: 完整处理, 跳过处理

**置信度标注**:
在素材分析和页面关系中标明信息来源可靠性的做法，例如 EXTRACTED、INFERRED、AMBIGUOUS 和 UNVERIFIED。置信度标注帮助后续检查和图谱表达。
_Avoid_: 关系类型, 重要性
