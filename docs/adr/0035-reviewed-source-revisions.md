# 受控素材更新与摘要候选

## 决策

工作台在可靠入库之上提供 Markdown 主动变化检查和素材摘要重新生成。生成与采用分开：候选只写应用数据，用户查看对照并确认后才更新正式知识库。目录检查是用户主动授权动作，历史来源快照不能变成后台扫描许可。

来源、内容版本、摘要候选和当前采用版本有独立身份。同内容重新生成是新的受控候选，不关闭普通入库的去重。采用使用稳定摘要路径、不可变原文版本与旧摘要归档，保留已有链接和历史阅读。

采用必须同时核对基础版本、正式摘要与生成内容哈希，复用可恢复发布和同库写入协调。外部未知内容不覆盖，不以自动重试代替用户确认。默认检索只采用可验证的当前受管版本，历史原文和旧证据仍可访问。

## 取舍

- 生成后直接覆盖会把模型结果和用户确认混为一体，也难以保护外部编辑，因此采用独立候选和版本校验。
- 每次重新生成都增加正式摘要页面会造成重复链接和过期召回，因此正式摘要保持稳定路径，历史版本另行保留供明确查看。

## 影响

- 原有首次入库与 Skill 完整整理职责保持一致，不另造实体／主题合并语义。
- 旧队列记录通过兼容读取和可证明的用户重新关联逐步接管，不能猜测丢失的来源目录。
- 候选和版本历史属于敏感用户内容，仍在现有应用数据范围保存，不增加凭证或配置来源。
- 删除来源只作观察提示；本次不提供自动删除知识或历史恢复覆盖。
