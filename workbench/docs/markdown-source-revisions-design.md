# Markdown 增量更新与摘要候选

## 范围与用户流程

在现有“入库任务”入口增加两项能力：主动检查已选择目录中的 Markdown 变化，以及基于已保留原文重新生成素材摘要。继续复用可靠入库的固定输入、任务恢复和发布保护；不增加目录监听、通用编辑器或实体／主题自动整理。

1. 用户选择或明确确认素材目录后检查变化，看到新增、修改、删除和未变化清单。重新打开面板或重启服务不会自动扫描外部目录。
2. 只为用户选中的新增、修改项生成候选。未变化项不触发模型；删除只提示并保留已有原文、摘要和引用。
3. 已完成素材可选择模型、填写可选的摘要改进要求，创建新的摘要候选；原入库任务保持完成。
4. 候选详情分别对照原文与摘要，显示模型、时间和版本。首次新增没有旧版时明确显示“无旧版本”。
5. 生成成功进入“待确认”，确认采用才更新正式摘要、索引和日志。关闭、刷新、切库及重启均不自动采用。
6. 版本记录提供已采用原文、摘要的只读查看和比较。本次不提供历史版本恢复覆盖入口。

## 身份和持久化

- 区分稳定来源身份、按原始字节计算的内容版本、独立候选操作身份和当前采用版本。相同内容重新生成不能覆盖旧生成结果，也不能复用首次入库的去重身份。
- 来源登记、候选、不可变输入、旧摘要归档与恢复记录保存在现有应用数据 `ingest/` 范围内，按用户内容保护，不存模型凭证。正文不进入轮询列表、URL 或默认日志。
- 已有 v1 入库记录缺少来源路径和目录。旧任务可以直接使用其保留快照重新生成；目录关联只能在用户重新选择后通过原路径与旧内容哈希的身份证明建立，不能按文件名或同内容猜测来源。无法关联的旧任务不参与删除判断。
- 来源目录登记不是后台读取许可。每次检查都由用户动作重新取得扫描授权，持久候选恢复不重新读取外部来源；来源快照仍不等于长期扫描授权。

## 变化检查

- 只处理 Markdown，兼容大小写扩展名，沿用单文件 20 MiB、每批 100 MiB／500 项限制。
- 扫描授权绑定真实根目录、精确文件集合和实际内容哈希。接受候选前重新校验，不能把新出现或变动的文件混入旧选择。
- 只有同一根目录完整成功的扫描才能判断删除。不可读、截断、深度遗漏、目录替换和符号链接异常必须说明限制，不能把未读到的文件报告为已删除。
- 跳过的变化保持待处理；扫描观察与当前已采用版本分开。来源移动按旧来源缺失与新来源处理，不猜测改名。

## 候选与采用

候选状态为等待、生成中、待确认、保存中、已采用、失败、过期或取消。显式重试复用固定输入；同一次请求重放不得重复调用模型。生成只获得批准的单份素材和改进要求，不加载普通对话、全局 Skill、工具或其他知识库内容。

候选固定内容版本、基础采用版本、正式摘要完整字节哈希与生成结果哈希。确认采用时必须再次校验候选状态／版本、来源当前版本、目标摘要和候选结果。摘要被 Obsidian、对话工具或安全改名改变时拒绝覆盖，不能自动合并或恢复旧路径。已观察到更新来源的旧候选不能冒充最新版本。

采用与现有同库入库发布共用协调机制，并依赖逐文件内容保护处理外部写入。持久化保存中状态后才发布，发布采用可重放 write set；原文、摘要、索引、日志和版本指针在异常退出后能收口，恢复不重新调用模型，不重复追加索引日志。保存已开始时不承诺完整取消；取消成功后迟到生成结果不得写入。

正式摘要采用接管时确定的稳定路径，保留既有普通链接。不同内容版本的已发布原文路径和字节保持不变，旧摘要保存归档供历史查看。旧任务完成校验不能再把历史摘要哈希强套在当前页；默认检索排除可验证的受管历史版本，显式历史阅读和既有证据仍可核对，不隐藏用户另行改动的未知内容。

## 对照和界面保护

对照按需加载，以字节、行数和计算量限制保护长文。允许明确提示后显示受限对照，不得将展示截断或换行归一结果反写为原文。采用始终使用完整固定内容及哈希。

所有动作绑定知识库和不透明的来源／候选身份，沿用现有可信来源、启动凭证与统一错误边界。轮询只读取状态；`ready` 不触发自动采用。切库、关闭详情或连续操作后的迟到响应不得覆盖当前界面。

## 验收门槛

- 一份新增、一份修改、一份删除、一份未变：只生成选中的新增／修改，未变零模型调用，删除不改知识库。
- 同来源 v1→v2→v1、不同目录同名素材、同内容显式重新生成及请求重放均保持正确身份和版本关系。
- 待确认前正式知识库文件不变；刷新、切库和重启保持待确认。采用双击、双候选、部分发布恢复和取消晚到均有确定结果。
- 外部编辑、改名、删除、目录替换和符号链接不被覆盖；不完整扫描不误报删除。
- 旧原文引用仍可打开；旧摘要可从版本记录查看，新检索不会把受管历史副本当当前版本。
- 真实模型适配器的假模型测试证明只获得固定输入；状态、错误、日志和对照不含凭证。
- 中文、空格、Windows 路径与 CRLF、大文件对照预算均有回归；本机完整质量及真实浏览器流程通过，新增核心场景纳入原生 Windows CI。
